+

weighted_company_embeddings = {}
Loop.
for company in tqdm(companies):
    temp = company_question[
        company_question.company == company

    vectors = []
    weights = []
    for _, row in temp.iterrows():
        qid = row.question_id
        if qid in question_lookup:
            vectors.append(
                question_lookup[qid]
            )
            weights.append(
                row.frequency
            )
    vectors = np.array(vectors)
    weights = np.array(weights)
    company_vector = np.average(
        vectors,
        axis=0,
        weights=weights
    )
    weighted_company_embeddings[company] = company_vector

Function.
def company_similarity(
    company,
    embedding_df,
    top_k=10
):
    names = embedding_df.company
    X = embedding_df.drop(
        columns="company"
    ).values
    sim = cosine_similarity(X)
    idx = names[names == company].index[0]
    scores = sim[idx]
    top = np.argsort(scores)[::-1][1:top_k+1]
    result = pd.DataFrame({
        "Company":names.iloc[top].values,
        "Similarity":scores[top]
    })
    return result

Why this is stronger than just averaging
In an interview, you can say:
"I first implemented a simple mean embedding as a baseline. However, I realized that not all questions contribute equally to a company's interview profile. Since my dataset contains company-specific question frequencies, I built a weighted aggregation where frequently asked questions have greater influence on the company embedding. I compared both representations qualitatively through nearest-company retrieval."
That sounds like your design decision, not something copied from a tutorial.
One correction to my earlier suggestion
I would not normalize frequency by dividing through the global maximum (max() over all companies). That can let one extremely frequent question dominate.
A better approach is to normalize within each company before computing the weighted average:
temp = temp.copy()
temp["weight"] = temp["frequency"] / temp["frequency"].sum()
Then use temp["weight"] as the weights in np.average. This ensures every company's embedding is a convex combination of its own questions, making company vectors comparable regardless of how many questions or how much total frequency each company has. That's the version I'd recommend using in your final project.
